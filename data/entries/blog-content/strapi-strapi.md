# strapi

Open-source headless CMS in Node/TypeScript — model content types in the admin panel and every one gets an auto-generated REST API (GraphQL via the official plugin). The standard self-hostable content backend for JAMstack blogs, running on SQLite for dev and PostgreSQL/MySQL/MariaDB in production.

- Every one of the tracker's most-reacted issues is closed, so the loudest historical asks have largely been addressed — led by multi-site / multi-tenant support ([strapi/strapi#1465](https://github.com/strapi/strapi/issues/1465), 223👍), drag-and-drop ordering of entries in the list view ([#3946](https://github.com/strapi/strapi/issues/3946), 217👍), and media-library folders for organizing assets ([#8612](https://github.com/strapi/strapi/issues/8612), 204👍).
- API-querying and localization gaps drew the next tier of demand — deep filtering on component objects across GraphQL and REST ([#5124](https://github.com/strapi/strapi/issues/5124), 119👍) and field-level localization ([#12538](https://github.com/strapi/strapi/issues/12538), 79👍), both since closed.
- Auth and content-modeling conveniences round out the top requests: LDAP/CAS authentication ([#2312](https://github.com/strapi/strapi/issues/2312), 102👍), a slug field type ([#752](https://github.com/strapi/strapi/issues/752), 77👍), and data import/export ([#744](https://github.com/strapi/strapi/issues/744), 71👍).
- Actively maintained — 20 tagged releases at a ~7-day median cadence (latest 2026-07-08) — against a large ~522-issue open backlog (includes PRs); the README lists no adopters.
