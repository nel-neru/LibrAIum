# ant-design

React component library and design system from Ant Group — 60+ components including the deepest enterprise widgets in the React ecosystem (Table, Form, DatePicker), token-based theming with dark/compact algorithms, and locale packs for dozens of languages. The v6 line (current, releasing roughly weekly) requires React 18+ and defaults to CSS-variables theming for cheap runtime theme switching.

- Major-version migration threads dominate the top of the tracker: the v4 "in progress" and "is out" announcements ([#16911](https://github.com/ant-design/ant-design/issues/16911), 460👍; [#21656](https://github.com/ant-design/ant-design/issues/21656), 427👍) plus the v5 plan ([#33862](https://github.com/ant-design/ant-design/issues/33862), 422👍) are among the most-reacted, so consumers track its breaking-change roadmaps closely.
